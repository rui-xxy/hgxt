# 交互区域的布局稳定性

切换年份、车间、标签、筛选或分页时，同一个控件和相邻卡片不应因内容多少或换行而上下移动。可变内容必须先确定显示边界，再选择完整展示方式。

## 这次排查的结果

| 区域 | 触发条件 | 处理 |
| --- | --- | --- |
| 计划与完成／月度完成趋势 | 预测说明在车间和数值变化时换成两、三行 | 改成固定两行的短标签，完整内容保留在 `title`；两列都预留相同的说明高度 |
| 计划与完成／顶部 KPI | 车间清单、事项数字较长时换行 | 卡片改为响应式列数；说明收敛为数量和固定的两行区域，完整车间名保留在 `title` |
| 计划与完成／年份 | 新年份请求期间旧数据被清空 | 查询期间保留上一个完整结果，同时明确显示数据所属年份和正在加载的年份 |
| 计划与完成／产销与单耗 | 视图、车间切换后表格行数不同 | 表格放入有固定可视高度的内部滚动区，切换时回到表格顶部 |
| 能源中心／能耗表 | 电、汽、水的行数不同 | 复用同一内部滚动区，表头固定，切换时回顶部 |
| 物料与库存／原辅料 | 全部、预警的行数不同 | 复用同一内部滚动区，切换时回顶部 |
| 生产计划／单耗上限 | 不同车间的能源和原辅料行数不同 | 两列以指标目录中的最大行数预留空间，车间切换时下方位置不变 |
| 生产计划／年份 | 获取新年份的设置期间表格暂时为空 | 产量计划保留表格占位高度，数据未到时禁用车间输入切换 |
| 本周 vs 上周／车间卡片 | 车间名称、销量和单耗数字变长 | 一行数值与标签不换行；较窄时对次要文字省略，悬停可查看完整标签 |
| 表单总览、成员列表 | 搜索后从多页变为单页时，原本只在多页启用的固定表格高度被撤销 | 无论页数都使用同一个表格视口，避免筛选结果多少改变底部分页位置 |
| 丰联报表数据表 | 三车间与标准厂房字段数量悬殊，整表渲染造成切换卡顿 | 先切换车间，再切换产成品／原辅料／水电气；全部记录连续滚动，只渲染视口附近的行；固定两级表头和行高，编辑离开视口时先提交当前单元格 |

既有的事项分页和一般表单数据表使用固定的分页视口；丰联报表不分页，使用固定行高的虚拟滚动。车间主图本身有固定绘图区，明细表在内部滚动。正常编辑表单的字段增减属于有意的内容变化，不套用固定高度。

## 新界面的实现规则

1. 会在同一位置切换的表格、列表，使用 `hgxt-stable-viewport` 和 `stableViewportStyle`。视口高度按照预期行数和行高预留，并限制在当前窗口内；滚动条宽度常驻预留，筛选或切换后复位内部滚动位置。表头在视口中固定。
2. 指标卡片和图表旁的动态文字先定义行数。用简短文案在固定行数中展示关键数字；完整说明放在可访问的标题或详情中。不要仅靠 `min-height` 托住无限换行的原文。
3. 有异步切换的页面保持旧结果或等高占位；如果暂时显示旧结果，必须显示它所属的年份或范围。切换按钮的选中值与数据范围不得混淆。
4. 在窄屏上调整列数，给网格子项设置 `min-width: 0`。只在次要、可从其他位置查看的文字上使用省略号；事项等主要正文应完整换行，但放在稳定的列表视口里。
5. 验收时依次切换最少行／最多行、最短／最长文字、空数据／加载中，并检查 1440、1024、760 像素宽度和较矮窗口。观察控件和下一张卡片的屏幕位置是否变化，并确认没有横向挤出或内容不可访问。
